# AI Private Office V7.2 — Live Draft Jobs Beta + Option A Office

Includes six clickable desks, browser-local staff occupancy, character builder, and a server-side queue for real OpenAI draft jobs. CEO starts each job from an assigned task; the backend processes it asynchronously, stores results/status in the database, and the browser polls every four seconds after CEO login. Completed drafts move to CEO review; nothing is published or sent externally.

**This is NOT an unrestricted autonomous workforce.** Jobs are individually CEO-triggered; no continuous self-directed planning, background scheduling, independent multi-agent orchestration, external integrations, or secure shared staff memory. Queue execution uses in-process asyncio tasks and can be interrupted on Railway restarts; interrupted jobs are marked as such. Use a dedicated durable worker/queue for production. Job status is real, but numeric progress is not measurable; the UI must not infer completion percentages from job duration. Staff occupancy remains browser-local. People and signage embedded in the image are decorative, not dynamic.

**Security and deployment:** Do not use sensitive data. The existing CEO password/token authentication is a development-level safeguard, not production security. Configure OPENAI_API_KEY, CEO_PASSWORD, SESSION_SECRET in Railway Variables, not GitHub. For persistence use a managed database and a Railway volume at /app/data for SQLite/uploads; without a volume data can disappear on redeploy. Deploy one web process only for this beta. Extract ZIP and upload contents to repository root, not the ZIP itself. Preserve Railway Root Directory matching GitHub.
